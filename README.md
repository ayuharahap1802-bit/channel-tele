# BOLAPELANGI 2 Bot - Ultimate Pro v3.0

Bot Telegram Super Lengkap dengan fitur Auto Welcome, Auto Post Terjadwal, Broadcast System, Admin Panel, dan User Tracking.

## 🚀 Fitur Utama

### Core Features
- ✅ **Auto Welcome Member** - Sambut member baru di channel
- ✅ **Auto Post Terjadwal** - Posting otomatis ke channel sesuai jadwal
- ✅ **Broadcast System** - Kirim pesan ke semua user dengan queue system
- ✅ **Admin Panel** - Dashboard admin dengan berbagai fitur
- ✅ **User Tracking** - Lacak semua interaksi user
- ✅ **Statistics** - Statistik lengkap bot dan user

### Advanced Features
- ✅ **Multi-level Admin** - Super Admin, Admin, Moderator, Broadcaster
- ✅ **Granular Permissions** - Atur izin per admin
- ✅ **Message Templates** - Template pesan untuk broadcast
- ✅ **Scheduled Broadcast** - Jadwalkan broadcast di waktu tertentu
- ✅ **Database Backup** - Auto backup dan restore
- ✅ **Activity Logs** - Log semua aktivitas admin
- ✅ **Quick Replies** - Balasan cepat untuk kata kunci
- ✅ **Multi-language** - Dukungan multiple bahasa (ID/EN)
- ✅ **Feature Flags** - Nyalakan/matikan fitur sesuai kebutuhan
- ✅ **Health Check** - Monitoring kesehatan bot

## 📋 Daftar Perintah

### Perintah Publik
| Perintah | Deskripsi |
|----------|-----------|
| `/start` | Memulai bot dan menampilkan menu utama |
| `/help` | Menampilkan bantuan |
| `/info` | Informasi akun Anda |
| `/promo` | Lihat promo terbaru |
| `/stats` | Statistik bot |

### Perintah Admin
| Perintah | Deskripsi | Izin |
|----------|-----------|------|
| `/admin` | Dashboard admin | Admin+ |
| `/users` | Daftar user | can_manage_users |
| `/broadcast` | Kirim broadcast | can_broadcast |
| `/posts` | Kelola auto post | can_manage_posts |

### Perintah Super Admin
| Perintah | Deskripsi |
|----------|-----------|
| `/admins` | Kelola admin |
| `/settings` | Lihat pengaturan |
| `/set [key] [value]` | Ubah pengaturan |
| `/backup` | Backup database |
| `/logs` | Lihat log aktivitas |
